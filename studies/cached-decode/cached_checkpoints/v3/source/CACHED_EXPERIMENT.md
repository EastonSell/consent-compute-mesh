# Cached decode: prospective design

Status: source development; independent review required before retained execution.
This isolated copy preserves prior files. Base public commit: 276dd9bf0c3a5aefa73e3c0a4b45f9a806222522.

Pinned SmolLM2-135M-Instruct revision 12fd25f77366fa6b3b4b768ec3050bf629380bac, verified config/weights, existing Torch 2.5.1 / Transformers 4.46.3. CPU FP32 eager attention, batch one, no padding, no lossy codec. Two spawned workers, 15 layers each, one compute thread per process; controller reference runs sequentially with one thread. No listener, discovery, downloads, installs or physical network.

Each stage uses its own 15-entry DynamicCache, locally renumbered layer indices. Global token positions feed rotary embeddings and rectangular causal masks. No KV crosses the boundary. Commands identify epoch, monotonically increasing sequence, phase, prior cache position and input length. Reset advances epoch and requires both acknowledgments. Any malformed/out-of-order command, timeout or failed response poisons the session. A new process session starts with empty cache; reset cannot revive a poisoned session. Context maximum 64 tokens, decode exactly one token.

Weights are partitioned, not full-model replicated in workers. Tied embedding/output-head matrix is duplicated across the two workers (49152*576*4 = 113246208 bytes per copy). The controller additionally holds a complete reference model. Thus this comparison is NOT evidence of total memory savings. Cache byte counts are actual owned tensor storage, not RSS or allocator overhead. RSS is per-process peak, not simultaneous total peak.

Fixed retained schedule after independent review: three prefixes, token IDs [1,2,3,4], [25,100,200,300,400,500,600,700], [42]*16; eight autoregressive greedy decode steps each, compared to monolithic cached reference from the same prefix. These synthetic IDs are correctness probes, not linguistic/quality tasks. Prefill and each decode compare every vocabulary logit at the last input position, exact FP32 equality and exact greedy token. Record allclose(1e-4,1e-4) only as diagnostic; exact equality is the correctness gate. Full-vocabulary logits are saved, not only aggregate errors. Reset and replay first prefix after the three cases verifies isolation. Two fresh full runs verify deterministic logit bytes. No warmup, no speedup claim. Prefill and decode timing/bytes reported separately; cold prefill is explicitly included.

Resource gate: minimum 3 GiB available host/cgroup memory before model load; sequential stage loading and reference compute. Expected workload near 3 GiB but this is not a hard allocation cap; monitor aggregate live RSS and abort above 3 GiB. At most two worker compute threads active, no overlapping controller reference inference. Limit OpenMP/MKL/OpenBLAS environment threads to one. No system resource setting changes.

Retain exclusive output directories, running marker, fsynced JSONL rows before correctness assertions, full logits per step, exception/interruption record, final complete marker only after all cases and worker cleanup. Frozen hashes cover new source, protocol, tests and inherited source dependencies; inherited result artifacts excluded. Existing output rejected. Inject runner failures and interruption before/after a row; these are harness audits, not model benchmarks. A partial run is never completion. Independent review and prospective amendments must be recorded before retained runs. Development model smoke checks, if needed, are labeled separately and cannot select this schedule.

## Prospective v2 amendment (2026-10-22 07:52 UTC, before any model run)

Independent v1 review found that poll plus blocking recv_bytes could defeat deadlines on partial frames. Both pipe directions now execute through tracked bounded I/O tasks; any failure terminates peer workers before pipe closure and joins I/O tasks. Cleanup explicitly reports both process and I/O-thread termination. Synthetic spawned-child tests cover partial-frame timeout/cancel and blocked sends; fake responses test stale state, malformed metrics and failure during second-stage reset. Real subprocess SIGINT before/after a flushed row verifies interruption retention. This does not claim SIGKILL terminal-marker creation or filesystem/power-loss durability.

The resource monitor now fails closed on inspection errors, checks its flag immediately after reference loading and before worker startup, and checks cancellation before each worker spawn. Sampling is a 50ms best-effort guard, not a kernel hard memory cap; transient overshoot remains possible. Readiness uses exact integer typing.

## Prospective v3 amendment (2026-10-22 07:56 UTC, before any model run)

The reference now uses num_logits_to_keep=1, so its output-head GEMM shape matches stage1 rather than computing unused prefill-position logits. The correctness gate also requires identical saved FP32 bytes. Duplicate tensor-header keys now fail closed, matching strict command-header parsing. Both request and response frame sizes are recorded for both stages. The boundary-frame metric is the stage1 request, not total controller-mediated IPC traffic; final 49152-vocabulary FP32 logits themselves cost 196608 payload bytes per step. Worker seconds include input decoding and output packing, not only model compute.

Runtime/model identifiers and exact case coverage are retained. The independent no-inference artifact checker verifies all 36 row identities, 72 full-logit file sizes/hashes/finite values/argmaxes, autoregressive inputs, reset replay and cross-run deterministic bytes. It does not infer task quality.

Retention audit scope is explicit: injected assertions and subprocess SIGINT cover the Evidence component, not complete runner model/worker interruption behavior. Spawned-child I/O tests separately cover cancellation, partial-frame reads and blocked writes. These do not establish production reliability or hard OS enforcement. RSS is sampled; reference/model-load operations are cooperative and not forcibly deadline-limited. Any run-level failure must remain visible, and no retained run begins until independent final source review and a separately labeled bounded development equivalence smoke.
