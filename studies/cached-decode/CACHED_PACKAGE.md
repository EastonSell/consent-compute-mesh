# Cached-study package

This package includes the complete Python source and test files identified by frozen v4 hashes, required synthetic test data/examples, optional dependency pins and license, cached-study reports, all v1–v4 cached-source snapshots, failed/successful development evidence, and both retained runs' full raw arrays/rows.

Base repository: EastonSell/consent-compute-mesh, public commit 276dd9bf0c3a5aefa73e3c0a4b45f9a806222522. Development began in an isolated read-only copy of the then-current transport worktree. The package contains inherited Python dependencies explicitly, so cached inference does not rely on retrieving a changing branch. Historical transport/household results and figures are not included or reused as cached-decode evidence.

No model weights, environment binaries, credentials, private workflow skills or network services are packaged. A compatible existing runtime and locally available pinned model are required for inference. Exact package contents and SHA256 hashes appear in CACHED_PUBLIC_FILES.txt and CACHED_PUBLIC_SHA256.json. The SHA256 manifest excludes its own hash; hash the archive separately for transport integrity.

The active development smoke script is cached_checkpoints/development_smoke.py; archived copies under v3/v4 are source snapshots, not execution locations. Retained reproduction uses mesh.cached_experiment and mesh.cached_verify as documented in CACHED_RESULTS.md. Source-file changes intentionally invalidate the retained runner's frozen-manifest gate.
